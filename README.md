# 🎨 Figma‑Inspired Web Design Editor

A **Figma‑inspired design editor built with JavaScript** that lets users create, select, and manage visual elements on an artboard — directly in the browser. This project focuses on core editor concepts like element selection, layers, alignment, and a clean, modern UI similar to Figma.

> 🚧 This is an actively developing project focused on learning and implementing real‑world design‑tool architecture.

---

## ✨ Features

* 🖼️ **Artboard system** – central canvas for placing elements
* 🔲 **Rectangle & Text tools**
* 🖱️ **Click‑to‑select elements** with selection box
* 📚 **Layers panel** (syncs with artboard elements)
* 🎯 **Single‑selection logic** (only one element active at a time)
* 🧭 **Floating tools panel** (Figma‑style layout)
* ⚡ **Vanilla JavaScript architecture** (no heavy frameworks)

---

## 🛠️ Tech Stack

* **HTML5** – structure
* **CSS3** – layout & styling
* **JavaScript (ES6)** – editor logic & state management
